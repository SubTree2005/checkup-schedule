# Iconfont assets

These SVGs are generated from `code/iconfont-medical-icons` by
`scripts/prepare_iconfont_assets.ps1`.

- Login and information-row icons use a transparent background.
- Preparation icons keep distinct semantic colors.
- The add-exam glyph is white because the containing capsule supplies the fill.
- Existing examination-item icons and `icon-check.png` are intentionally not replaced.
