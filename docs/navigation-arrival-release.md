# 导航到达与项目完成修复

导航页点击“完成导航”时，将当前待开始项目设为进行中，再返回项目页显示“完成本项”。完成后只打开下一项目的导航。若开始失败则留在导航页重试；途中重排改变目标时，刷新新目标路线，不开始旧项目。

小程序同时包含导航页 56rpx 的跳过按钮、起终点标签避让、同一楼梯连续跨层时隐藏中间楼层的修复。中间层有实际步行路线或必经导诊点时仍显示该层。楼层隐藏只影响展示，不扣减全程时间和距离。

## 更新步骤

1. 拉取合并后的 main。在微信开发者工具中打开 `apps/miniprogram`，重新编译、上传；手机使用对应体验版，正式版需发布后生效。仅更新 Web 或后端不会改变这些小程序页面。
2. 部署新版后端及管理端，支持已有导入记录的报告更新。
3. 用原账号与密码重新导入 `examples/patients/campus-student-demo.json`，更新已有报告文字；不更改 recordKey。小程序刷新历史记录。

## 验证场景

- 检验科到 3F 内科：同一楼梯直达时只显示 1F、3F；1F 起终点文字分开，3F 蓝线连接楼梯与内科。
- 需要在 2F 换楼梯或停靠导诊点时保留 2F。
- 完成导航后项目页直接显示“完成本项”；点击完成后导航到下一科室，不重复导航到刚到达的科室。
- 历史报告使用 JSON 中的标题和结论，无自动附加的演示前缀。

本地自动化覆盖流程、重复点击、失败重试、楼层过滤、标签避让及重复导入；真机显示须在上传后的版本中复核。
