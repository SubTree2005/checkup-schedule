# 放射检查后的导航起点

2026-09-09，用户明确确认检查后出口不是综合服务中心登记处，而在“综合服务中心左边一点”。

用户随后提供蓝点局部图 `gis/source/images/radiology_exit_user.png`，明确标注综合服务中心左侧、放射科北侧的开口。依据该图补齐原先漏描的狭窄通道，开口概化为像素 [551,402]–[575,402]，中点 [563,402]，通过 [563,387] 接入已有公共走廊。它是图上确认的门位，不是现场测绘结果。

检查完成后从该开口出发；检查前沿“起点 → 综合服务中心 → 放射科开口”的连续路线行走。综合服务中心的 GIS POI 通过 `guidanceFor` 绑定放射科，不再把登记点替代最终科室。若管理员已明确绑定科室入口，则沿用管理员设置。

兼容定位必须匹配原始放射科区域、综合服务中心点位和走廊端点坐标，且连接处于开放状态；不同 GIS 或被修改、关闭的连接不得自动套用。
